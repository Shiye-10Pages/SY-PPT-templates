## 它能做什么

- 把 Markdown 渲染成 100vh 满屏滚动叙事
- 一份输入，两种产物：长页 HTML + 分享卡片 ZIP
- 一键切换主题：发布会风 / 瑞士极简
- 没有云端、没有账号、没有水印
