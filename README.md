# 十页 PPT 模板

把一段 Markdown 变成可分享的滚动长页 + 分享卡片，**20 个精选模板，14 个面向中国本地场景**。

一份输入，两种传播姿势：
- **长滚动叙事页** — 单 HTML，发给别人双击就能看
- **分享卡片集** — 每屏一张 PNG，发小红书 / 朋友圈 / 视频号

无云端 · 无账号 · 无水印 · 全开源。

## 试一下

```bash
pnpm install
pnpm dev
```

打开 `http://localhost:5173`，左侧粘贴 Markdown，右侧实时预览。右上角切主题、导出 HTML、导出卡片 ZIP。

## Markdown 语法

```markdown
# 封面大标题
副标题写在第二行（可选）

---

## 区块小字
# 大段巨字独占一屏

---

> 90%
注解文字 / 大数字屏

---

> 90K / 1.5M / $1.2K
带 K M B 后缀也认

---

> 这是一段引语
配在引语下面的署名

---

## 列表标题
- 要点一
- 要点二

---

## 套餐名称
¥ 38 / 位
~~原价 98~~
限时三天

---

## 联系我们
📞 138-0013-8000
💬 微信: example-account
📍 北京市朝阳区

---

@qr
扫码加微信领优惠券
店铺名 · 分店

---

@poster
今晚 8 点
# 大字标题
副标题 / 描述
[CTA 按钮]
```

规则：
- `---` 分屏（或写 `## ` 自动起新屏）
- `# Title`（首屏）→ 封面
- `# Big` 单独一屏 → 巨字标题
- `> 数字` → 大数字屏
- `> 文字` → 引语屏
- `- / 1.` 列表 → 编号列表屏
- `¥ NN / ~~原价~~` → 价格卡（餐饮 / 教培 / 房产场景）
- 行首 `📞💬📍📧🌐` → 联系信息（B 端必备）
- `@qr` 起头 → 二维码占位屏
- `@poster` 起头 → 海报头（适合 9:16 直播预告）

## 技术栈

- Vite + React 18 + TypeScript
- Tailwind CSS v4（CSS variables + container queries 驱动主题）
- `html-to-image` + `jszip`（前端 PNG + ZIP，无后端）

## 加自定义主题

1. 在 `src/themes/<id>/` 加 `theme.css`（在 `[data-theme="<id>"]` 下定义 CSS variables）
2. 同目录加 `meta.ts` 导出 `ThemeMeta` 对象
3. 在 `src/examples/<id>.md` 加一份配套示例
4. 重启 dev server，主题自动被 Vite glob 识别
